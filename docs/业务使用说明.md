# 业务使用说明

1. 单店可按“门店名称”或“详细地址”查找。城市、区县默认可以留空；有可靠信息时再填写，错误的行政区会形成硬冲突。
2. 候选结果先核对名称、地址、地图位置和评分明细。只有名称高度一致、城市一致、总分不低于 85 且无硬冲突时才允许自动确认。
3. 默认分析住宅小区、小学和幼儿园；可增加其他分类。半径可用预设或自定义，最多 5 个、最大 50 公里，超过 10 公里需要二次确认。
4. 点击“开始周边 POI 分析”，完成后可在 POI 分布、商圈画像和 POI 明细三个标签间切换。
5. 商圈画像会给出商圈名称、类型、能级、业务适配度、竞争压力、可信度和证据。它是 POI 结构规则推断，不代表人口、客流、消费或销售预测。
6. 批量场景打开“批量导入”，下载模板并填写门店名称或详细地址，二者至少填写一项。
7. 上传 Excel 或 CSV，检查字段映射和前 20 行预览；对地址级定位结果和低置信度候选逐一确认。
8. 在“分析任务”中生成批量商圈画像，按类型、能级、适配度和竞争压力筛选排序，再导出 Excel。
9. 普通导出包含门店汇总、POI 明细、待确认门店、失败记录、搜索配置；商圈分析后还包含商圈汇总、商圈特征明细和商圈评分配置。

> 演示模式会持续显示黄色提示。只有配置真实高德 Key 并关闭 Mock 后，结果才来自真实高德接口。
