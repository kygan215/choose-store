# 历史活动数据：确认口径与导入说明

此模块记录门店已完成活动的**活动商品实际销售额**，单位为元。它用于查阅和导出，不参与现有 POI 评分、选址推荐或品牌门店搜索规则。

## 原表与一场活动

首版接受 `.xlsx` 宽表：一行一家门店，`门店名称` 为必需列，混合品牌文件可增加 `品牌` 列，`省份`、`城市`、`地址`、`高德 POI ID` 可选。每个日期段列对应一次活动；上传时填写默认年份，再逐列核对完整起止日期与可选活动名称。

| 品牌 | 门店名称 | 10月1日-10月7日 | 4月29日-5月3日 |
| --- | --- | ---: | ---: |
| 好想来 | 湖北鄂州鄂城吾悦广场店 | 1000 |  |
| 好想来 | 湖北鄂州鄂城吴王广场店 | 0 | 2000 |

- 非空数字是活动商品销售额；`0` 表示活动已完成且零销售；空白表示该场活动不存在，重导入空白**不会**删除旧记录。
- 跨年活动的整场金额归入开始年份。按年和自选日期范围筛选时，都按开始日期判断，金额不按天拆分。
- 金额原样保存，并标明是否已扣退款；口径未知时明确标识。汇总名为“原始上报销售额”，混合退款口径时给出提示。没有记录金额与零销售严格区分。
- 如果一个门店同一日期段确有两场不同活动，当前规则不支持合并；需要先调整原数据的活动标识与时间口径。

## 门店关联与历史保存

按唯一的高德 POI ID 且品牌、省市不冲突时才能自动关联当前品牌库。仅从“湖北武汉…”等名称前缀推断的地区是候选，不是已确认关联。同名、缺 POI ID 或有冲突的门店进入独立待匹配清单，管理员可逐个或批量确认；候选未列出时可继续按名称、地址或 POI ID 搜索。找不到当前门店的老店可设为“仅历史门店档案”；不会计入当前品牌门店总数。若创建档案后暂未补录活动，可在待匹配页找回并继续补录。

每场活动保存发生时的门店名称、品牌、省市及地址快照，后续改名、迁址、停业或从当前库移除，都不改写当时记录。重复导入需预览冲突，明确选“保留旧值”或“更新”，更新与手工修正均留痕。撤销必须单独操作并填写原因。原始 Excel 文件、工作表与单元格位置保留供管理员核对。

## 查看与导出

“历史活动数据”主页一店一行，可按活动时品牌、省市、年份、日期和退款口径筛选，显示活动门店数、场次、原始上报销售额；点击门店查看逐场活动。品牌门店库名册和批量分析任务导出都可勾选历史数据，默认全历史，也可设置日期范围。主表保持原有门店行并附活动次数、最近活动、销售额等汇总列；另附逐场“历史活动明细”工作表。没有准确匹配的任务门店，金额留空并标记“历史数据未匹配”，不能写成零销售。

管理员默认可维护和查看；其他账号的查看、导出权限分别授予。导出权限要求同时具备查看权限。所有历史销售接口和下载都应复核权限。

## 日历标注

活动日期覆盖周末、国务院公布的放假区间或传统节日当天时，分别自动标注。标签只是日历事实，不自动改活动名称，也不自动把 618、双十一等商业活动认作节假日。尚未公布年度安排的年份不推测官方假期。

当前官方假期数据来源：[2023 年](https://app.www.gov.cn/govdata/gov/202212/08/495070/article.html)、[2024 年](https://www.gov.cn/zhengce/content/202310/content_6911527.htm)、[2025 年](https://www.forestry.gov.cn/c/www/szxx/594663.jhtml)、[2026 年](https://zwfw.gansu.gov.cn/wenxian/zczx/zwdt/art/2025/art_f430743a887f45109bc8850775c1d89e.html)的国务院办公厅通知。后续年度公布后需增加对应区间。
