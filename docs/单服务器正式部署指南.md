# 店界 POI 单服务器正式部署指南

## 1. 适用规模

当前正式版按约 30 名内部用户设计。推荐服务器最低配置：

- 4 核 CPU
- 8 GB 内存
- 100 GB SSD
- Ubuntu 24.04 LTS
- 公网或网关可访问的 TCP 7090（可通过 `HTTP_PORT` 调整）

当前测试阶段使用 HTTP 7090。443、证书和域名由后续网关承担，服务器暂不开放 443。

## 2. 服务结构

- `nginx`：唯一对外入口，容器内监听 80，服务器默认映射至 7090。
- `web`：Vinext 网页服务，不直接暴露端口。
- `api`：Node API，负责登录、导入、查询、导出和权限检查。
- `worker`：Redis 队列消费者，执行高德、批量 POI 和 DeepSeek 任务。
- `postgres`：业务数据、用户、会话、任务、AI 历史和审计日志。
- `redis`：任务队列、登录防爆破和接口限流。
- `backup`：每天生成 PostgreSQL 压缩备份，默认保留 14 天。

PostgreSQL、Redis、API、Worker 和网页端口均不对公网开放。

## 3. 第一次部署

服务器安装 Docker Engine、Docker Compose Plugin 和 Git，然后：

```bash
git clone https://github.com/kygan215/choose-store.git
cd choose-store
cp .env.production.example .env.production
chmod 600 .env.production
```

编辑 `.env.production`：

- `POSTGRES_PASSWORD`：至少 32 位随机密码。
- `ADMIN_EMAIL`：首次管理员邮箱。
- `ADMIN_PASSWORD`：至少 16 位随机密码。
- 填写三个高德配置和 DeepSeek Key。
- HTTP 测试阶段保持 `APP_ORIGIN=`、`COOKIE_SECURE=false`。

可用以下方式生成随机密码：

```bash
openssl rand -base64 36
```

启动：

```bash
sh deploy/server-init.sh
```

## 4. HTTP 7090 验收

```bash
sh deploy/smoke-test.sh http://127.0.0.1:7090
```

再用浏览器访问：

```text
http://服务器IP:7090/
```

使用 `.env.production` 中的管理员邮箱和密码登录。登录后应完成：

1. 搜索并分析一家门店。
2. 导入至少两家门店并运行完整分析。
3. 生成单店 AI 分析和 2–10 店 AI 对比。
4. 导出单店和批量报告。
5. 在“账号管理”创建普通成员，并验证成员可以登录。

## 5. 网关和域名阶段

HTTP 7090 验收通过后，再提供以下信息：

- 最终访问域名。
- 网关回源使用服务器内网 IP 还是公网 IP。
- 网关是否终止 HTTPS。
- 网关转发的真实客户端 IP 请求头名称。

若网关终止 HTTPS：

1. 网关将域名的 HTTPS 流量回源至服务器 7090。
2. 设置 `.env.production` 中 `APP_ORIGIN=https://最终域名`。
3. 设置 `COOKIE_SECURE=true`。
4. 在高德控制台把最终域名加入 JS Key 白名单。
5. 执行 `docker compose --env-file .env.production up -d --build api web worker`。

## 6. 日常运维

查看状态：

```bash
docker compose --env-file .env.production ps
```

查看 API 和队列日志：

```bash
docker compose --env-file .env.production logs --tail=200 api worker
```

更新版本：

```bash
git pull
docker compose --env-file .env.production build
docker compose --env-file .env.production up -d
```

备份位于 `backups/`。建议再同步到服务器之外的安全存储。

## 7. 安全要求

- 不要把 `.env.production` 提交到 Git。
- 正式部署前更换曾在聊天或截图中出现过的 API Key。
- 服务器安全组只开放管理来源 IP 的 22 和测试或网关回源所需的 7090。
- PostgreSQL 5432、Redis 6379、API 8000、网页 3000 不得开放公网。
- 接入网关后，可以限制 7090 仅允许网关回源 IP 访问。
