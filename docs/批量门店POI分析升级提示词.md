# 批量门店 POI 分析升级提示词

请在现有“门店周边 POI 搜索与分析平台”上进行增量升级，保留已经可用的单门店分析、批量上传、字段映射、门店候选匹配、人工确认、商圈画像和潜在人群画像能力，不重写项目架构。

## 核心目标

让通过 Excel、CSV 批量导入的每一家门店，都拥有与单门店分析一致的完整 POI 分析能力，并能在批量任务中逐店查看、导出报告和横向对比。

## 功能要求

1. 批量任务完成门店匹配后，按照任务配置的搜索半径和 POI 分类，对每一家已确认门店执行真实 POI 查询、去重、距离计算和距离分层。
2. POI 结果必须同时关联批量任务和门店，查看某个批量任务时不得混入该门店其他历史任务的数据。
3. “分析任务”页面应提供任务级操作：开始或继续匹配、处理候选、运行完整分析、查看分析对比、导出任务总报告。
4. 每个门店提供“查看详情”入口。详情至少包含：
   - POI 分布地图与搜索圈层；
   - POI 分类数量统计；
   - 商圈画像；
   - 潜在人群、年龄倾向、消费环境和商场线索；
   - 可筛选或浏览的 POI 明细。
5. 每个门店支持单独导出 Excel 报告，报告至少包含门店概览、POI 明细、商圈汇总、商圈特征、潜在人群画像和分析配置。
6. 批量任务支持总报告导出，保留所有门店汇总、全部 POI 明细、失败记录、待确认记录、商圈画像和潜在人群画像。
7. 多店对比至少展示：POI 总量、主要分类数量、商圈类型、商圈能级、业务适配度、竞争压力、主要潜在人群、年龄倾向、消费环境指数和可信度。允许选择 2 至 4 家门店进行重点对比。
8. 重复运行同一任务时不得为同一家门店产生重复画像；旧任务仍可重新运行以补齐新增的 POI 明细。
9. 明确标注数据来源、截断状态和推断限制。潜在人群、年龄和消费能力只能称为基于周边环境的代理推断，不能表述为真实人口、客流或销售预测。

## 接口与数据要求

- 增加批量任务门店列表接口。
- 增加批量任务下单个门店详情接口，返回门店、任务配置、POI、分类统计、距离统计和最新画像。
- 增加批量任务下单个门店报告导出接口。
- 扩展批量对比接口，返回每店的任务内 POI 统计。
- 所有接口继续使用统一的 `success/data/message/request_id` 响应结构和中文错误信息。

## 验收标准

- 使用至少 5 家门店的 Excel 完整走通：上传、字段映射、创建任务、门店匹配、完整 POI 分析、逐店详情、多店对比、单店导出和总报告导出。
- 自动化测试覆盖任务数据隔离、逐店详情、重复运行不重复、单店导出和总报告导出。
- 前端构建、代码检查和后端测试全部通过。
- 在本地页面实际验证主要按钮、详情切换和下载入口可用。
